**Datum:** 2026-06-26

**Navazuje na:** [docs/16](16-security-audit.md), [docs/17](17-funkcni-review.md), [PROJECT-LOG.md](../PROJECT-LOG.md).

Tento dokument je postup, jak v1.1 sestavit ve WSL2 a ověřit na telefonu.

## 0. Důležité — rootfs se NEmusí rebuildovat

Všechny změny v1.1 jsou v **Kotlin / manifest / gradle**. Asset `app/src/main/assets/rootfs.tar.gz`
z v1.0 zůstává platný → **pro build APK stačí `./gradlew`**, `build-bundle.sh` spouštět nemusíš.
Sekce SHA256 v `build-bundle.sh` (krok 3) je relevantní **jen když budeš rootfs znovu generovat**.

---

## 1. Sestavit APK (WSL2)

Projekt se buildí na WSL2 (`local.properties` → `sdk.dir=/home/.../android-sdk`).
Pozor na mezery v cestě — pokud je projekt pod cestou s mezerami, vytvoř symlink (viz README).

### Varianta A — release (skutečný v1.1 deliverable, S1)

Jednorázově vytvoř keystore (mimo repo) a vlož údaje do `local.properties`:

```bash
keytool -genkeypair -v -keystore ~/canonprint-release.jks -alias canonprint \
        -keyalg RSA -keysize 4096 -validity 10000
```

`local.properties` (přidat k existujícímu `sdk.dir`):
```properties
RELEASE_STORE_FILE=/home/ty/canonprint-release.jks
RELEASE_STORE_PASSWORD=...
RELEASE_KEY_ALIAS=canonprint
RELEASE_KEY_PASSWORD=...
```

Build:
```bash
JAVA_HOME=/usr/lib/jvm/java-17-openjdk-amd64 ANDROID_HOME=~/android-sdk \
  ./gradlew assembleRelease
# → app/build/outputs/apk/release/app-release.apk
```

> Tímhle se ověří, že **R8 minify + `proguard-rules.pro` (keep commons-compress)** prošlo.
> Bez keystore zůstane release APK nepodepsaný a nepůjde nainstalovat.

### Varianta B — debug (rychlá iterace, neověří R8 ani signing)

```bash
JAVA_HOME=/usr/lib/jvm/java-17-openjdk-amd64 ANDROID_HOME=~/android-sdk \
  ./gradlew assembleDebug
# → app/build/outputs/apk/debug/app-debug.apk
```

**Pokud build spadne:** nejpravděpodobnější je R8 v release (chybějící keep). Zkus napřed `assembleDebug`
— když projde debug a spadne jen release, je to R8/proguard a doplní se keep pravidlo.

## 2. Instalace na telefon

```bash
adb install -r app/build/outputs/apk/release/app-release.apk
```
> Po reinstalaci přepni tiskovou službu **OFF → ON** (Nastavení → Tisk → UFR-II), aby se služba znovu navázala.

## 3. (Volitelné) Rebuild rootfs s SHA256 ověřením (S3)

Jen pokud měníš/aktualizuješ knihovny v rootfs. `scripts/build-bundle.sh` je teď **fail-closed**:

1. Spusť `./scripts/build-bundle.sh` — stáhne `.deb` přes `https://`, spočítá SHA256 a protože
   jsou hashe `PENDING`, **vypíše vypočtené hodnoty a skončí** (nic nerozbalí).
2. Zkopíruj vypsané hashe do pole `SHA256[]` v `build-bundle.sh` (nahraď `PENDING`).
3. Spusť znovu — teď se každý balíček ověří proti hashi a teprve pak rozbalí.
4. Vznikne nová `rootfs.version` (sha256 tarballu) → RootfsManager v appce automaticky re-extrahuje.
